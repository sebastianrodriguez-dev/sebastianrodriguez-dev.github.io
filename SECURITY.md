# Security policy

This repository publishes a static GitHub Pages site. The public pages run no JavaScript or server-side code, accept no form submissions, set no cookies, and load no third-party assets. A restrictive page-level Content Security Policy blocks scripts, connections, frames, objects, media, workers, and form actions.

## Report a concern

Do not put passwords, Apple Account details, payment information, recovery or verification codes, private screenshots, receipts, device identifiers, or other sensitive information in a public repository post or message.

For a NookShift security or privacy concern, email `nookshift.support.gz7il@passmail.net`.

For an All Four in Place security or privacy concern, email `all-four-in-place-support.78efy@passmail.net`.

The repository does not accept public issue reports. Use the monitored address published on the affected app's support page. Include only the affected public URL, a clear description, and reproduction steps that contain no private data.

## Scope

Reports about this site, its public content, exposed files, broken security controls, or misleading privacy statements are in scope. App-binary issues should go to the support address published for that app.
